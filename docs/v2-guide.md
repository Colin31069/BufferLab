# BufferLab V2 使用與資料指南

## 工作流程

1. 在「設定配製條件」選擇內建或自訂配方並完成理論計算。
2. 核對結果中的驗證狀態、配方版本、警告、試劑需求、計算依據及 SOP。
3. 在「實際配製紀錄」填寫實驗名稱、實際體積、溫度、pH、試劑批號／效期／實際用量及備註。
4. 按「儲存配製紀錄」。再次儲存相同紀錄會保留 ID、更新修改時間並增加修訂次數。
5. 從紀錄列表依名稱、緩衝液或配製日期搜尋；可開啟、複製為新批次、刪除或列印／另存 PDF。

## 自訂資料庫

- 內建試劑與配方唯讀，可以複製成自訂副本。
- 固體試劑需要分子量；來源連結只接受 `http` 或 `https`。
- 固定配方支援莫耳數、固定質量、固定體積與庫存液體積。
- 成對酸鹼模型需要 pKa、有效範圍及酸／鹼型試劑。
- 滴定指引模型計算緩衝劑總量，但不預測 HCl／NaOH 精確用量。
- 溫度係數為選填；只有在有可靠來源時才應填寫，同時必須設定適用溫度範圍。
- 所有自訂內容都會在畫面與 PDF 顯示「使用者自訂／未經 BufferLab 驗證」。

## 紀錄與版本

- 理論計算結果採 `schemaVersion: 2`，保存 App 版本、資料版本、配方版本、來源與試劑快照。
- 編輯自訂配方會增加其版本；既有配製紀錄仍使用建立時的完整快照。
- 配製紀錄可隨時修改，不鎖定，也不保存每一次修改內容；只保留建立時間、最後修改時間與修訂次數。
- 「最近計算」只是快速重載表單；只有按下「儲存配製紀錄」才會建立正式紀錄。

## V1 遷移與離線限制

- 首次啟動 V2 時會複製 V1 的主題、偏好與最近計算；V1 儲存鍵不會被刪除。
- 遷移可重複執行，不會重複加入同一批 V1 歷史。
- 損壞或未知的本機資料會被忽略，不阻止計算器啟動。
- 所有資料僅存在瀏覽器 `localStorage`。若容量不足，儲存會失敗並保留既有資料。
- V2 不提供機器可還原的匯出格式；清除瀏覽器資料前，請將重要紀錄另存 PDF。
